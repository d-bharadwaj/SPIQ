# Cancer Genomic Biomarker Data

Starter code and dataset for PCBO biomarker feature-selection problems.

Sample instances live in `samples/n8`, `samples/n10`, `samples/n12`, `samples/n14`, and `samples/n20`. Load them with `biomarker_data.paths.sample_data_dir(n_qubits)`.

Use `examples/spiq_biomarker_workflow.ipynb` for the public SPIQ workflow on this data.
